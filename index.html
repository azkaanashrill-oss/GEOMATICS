📐 Rumus & Solusi Penyelesaian Pengukuran Waterpass

1. Perhitungan Jarak (m) per Slag:
$$\text{Jarak Posisi I (Atas)} = D_{\text{belakang, Pos I}} + D_{\text{muka, Pos I}}$$ $$\text{Jarak Posisi II (Bawah)} = D_{\text{belakang, Pos II}} + D_{\text{muka, Pos II}}$$ $$\text{Jarak Rata-rata} = \frac{\text{Jarak Posisi I} + \text{Jarak Posisi II}}{2}$$
2. Beda Tinggi Posisi I & II:
$$\text{Beda Tinggi Posisi I} = BTB_{\text{Pos I}} - BTM_{\text{Pos I}}$$ $$\text{Beda Tinggi Posisi II} = BTB_{\text{Pos II}} - BTM_{\text{Pos II}}$$
3. Beda Tinggi Rata-Rata & Koreksi:
$$\text{Rata-rata} = \frac{\text{Beda Tinggi Pos I} + \text{Beda Tinggi Pos II}}{2}$$ $$\text{Koreksi} = \frac{\sum \text{Rata-rata} \times -1}{\text{Jumlah Slag}}$$
4. Akumulasi Beruntun Tinggi Titik (Posisi I, II, & Hasil):
$$\text{Tinggi Titik 1 (Posisi I Beruntun Kebawah): } T_{1, \text{TP}_i} = T_{\text{sebelumnya}} + \Delta H_{\text{Pos1}, i} + \text{Rata-rata}_i + \text{Koreksi}_i$$ $$\text{Tinggi Titik 2 (Posisi II Beruntun Keatas): } T_{2, \text{TP}_i} = T_{\text{sesudahnya}} + \Delta H_{\text{Pos2}, i} + \text{Rata-rata}_i + \text{Koreksi}_i$$ $$\text{Hasil (Rata-rata Final): } H_{\text{TP}_i} = \frac{T_{1, \text{TP}_i} + T_{2, \text{TP}_i}}{2}$$
